# 队列观测范围

投产年份仅years中年度，历史桶在这之前，historical_buckets的coefficients为该桶总量对各年末存量的已给线性系数。底层变量键region:year，历史变量键bucket:id。新投产在同年末年龄0，存活表超出长度一律0。

原始区间全部闭区间，可缺上限表示无穷。新增仅非负，无隐式容量上限。aggregate_constraints和queries可引用底层及历史变量。代表解只惩罚同地区相邻投产年份差平方，不惩罚历史桶；再最小总新增，再按变量名升序字典序，历史桶仍平局则按其ID排序。

缺年不产生方程，冲突和无界均是分析结论。来源行ID稳定，资料读取器只检查年份顺序和身份，不构造矩阵或求界。
